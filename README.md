# Snake 🐍

Ett Snake-spel som körs direkt i webbläsaren (dator och mobil). Heja GAIS! 💚🖤

## Spela
- **Dator:** piltangenter eller WASD, Space för paus.
- **Mobil:** knappar på skärmen eller svep.
- Väggarna är öppna: du kommer ut på andra sidan.
- Gyllene äpplen, kombopoäng, power-ups (🐢 slow-motion, 👻 spökläge) och stenar gör det lite svårare.
- Ditt personbästa sparas i webbläsaren.

## Publicera med GitHub Pages
1. Gå till **Settings → Pages**.
2. Under *Build and deployment*, välj **Deploy from a branch**, branch `main` och mappen `/ (root)`.
3. Efter någon minut finns spelet på `https://<ditt-användarnamn>.github.io/<repo-namn>/`.

Spelet består bara av `index.html`, `style.css` och `game.js` och behöver ingen server eller byggsteg.
